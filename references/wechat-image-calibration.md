## Current Blocker

Browser policy currently blocks navigating to WeChat public platform from the OpenClaw dedicated browser. Calibration cannot continue until one of these is true:

1. Browser policy allows `mp.weixin.qq.com`, or
2. The user opens the WeChat publishing backend manually in a browser/profile that OpenClaw can inspect/control, or
3. A different approved browser automation path/provider is configured.
